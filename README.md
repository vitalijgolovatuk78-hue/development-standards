# development-standards

Постійна база правил і практик для наших програмних проєктів.

## Основні документи

- [Стандарт Java-розробки](docs/JAVA_DEVELOPMENT_STANDARDS.md) — сучасна Java, архітектура, Spring Boot, SQL/JPA, REST API, тестування, безпека, DevOps, продуктивність та багатопотоковість.
- [Стандарти написання коду](docs/CODE_WRITING_STANDARDS.md) — 10 основних правил, робочий процес від аналізу до перевірки та принципи ухвалення технічних рішень.

## Тестовий проєкт

- [Hello World](hello-world/Main.java)

Стандарти можуть доповнюватися, коли ми знаходимо кращі практики, інструменти або підходи. Зміни мають зберігати головний принцип: якість, безпека та підтримуваність важливіші за швидкість написання коду.
